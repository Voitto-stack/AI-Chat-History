在任何会话中都必须以最快速度解决用户问题，同时保证不出错。速度是核心要求，不是可选项。

**Why:** 用户多次强调执行太慢，明确要求每个会话都要最快。提速必须靠我自己的流程优化，不能把责任推给用户，也不能靠降低质量来换速度。

**How to apply:**
- 能并行的工具调用全部并行，绝不串行等待
- 先给结论再补细节，不做冗余解释
- 优先命中记忆和已有 skill，减少无效搜索
- 少确认、少废话、少重复，信息足够就直接推进
- 遇到需要本质判断的问题仍按事实推断，不为快而乱猜
- 这条规则适用于所有会话，不限当前对话
