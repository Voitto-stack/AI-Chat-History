缺失的 15 个变量（minerva-server 需要）：

1. `MONITOR_DATABASE_URL` - 监控数据库连接
2. `OSS_ACCESS_KEY_ID` - 阿里云 OSS 访问密钥
3. `OSS_ACCESS_KEY_SECRET` - OSS 密钥
4. `OSS_BUCKET` - OSS 存储桶
5. `OSS_ENDPOINT` - OSS 端点
6. `OSS_REGION` - OSS 区域
7. `OSS_CDN_HOST` - CDN 加速域名
8. `FEISHU_CLIENT_ID` - 飞书 App ID
9. `FEISHU_CLIENT_SECRET` - 飞书密钥
10. `FEISHU_REDIRECT_URI` - 飞书 OAuth 回调
11. `FEISHU_STATE_SECRET` - 飞书 State 密钥
12. `TIM_SDK_APP_ID` - 腾讯云 IM SDK ID
13. `PROTO_GATEWAY_URL` - Proto Gateway 地址
14. `PROTO_GATEWAY_USERNAME` - Proto 用户名
15. `PROTO_GATEWAY_PASSWORD` - Proto 密码
