两个页面数据不一致的原因

  图1 - PWA Databoard（显示 $78.00 / 33单）

  数据来源：pwa_daily_data 表（monitor 库），字段
  video_call_income 和 video_call_count

  关键：
  - 只统计 真实视频通话收益（不含 Mock）
  - 数据来自每日汇总表，由定时任务按天聚合写入
  - tooltip 写的就是"真实视频收益（不含Mock）"

  图2 - 通话订单（显示 $94.90 / 208笔）

  数据来源：user_call_order 表（主库），直接查原始订单

  关键：
  - 查询条件是 status =
  'PAID'，包含所有订单类型（VIDEO_CALL + MOCK_VIDEO）
  - totalAmount 是对 所有 PAID 订单的 amount 求和，包含
   Mock 视频
  - 208 笔包含了大量 amount=0 的 MOCK_VIDEO 订单

  差异拆解

  ┌───────┬───────────────────┬───────────────────┐
  │ 维度  │   PWA Databoard   │     通话订单      │
  ├───────┼───────────────────┼───────────────────┤
  │ 数据  │ pwa_daily_data（  │ user_call_order（ │
  │ 源    │ 汇总表）          │ 原始表）          │
  ├───────┼───────────────────┼───────────────────┤
  │ 订单  │ 仅 VIDEO_CALL     │ VIDEO_CALL +      │
  │ 类型  │                   │ MOCK_VIDEO        │
  ├───────┼───────────────────┼───────────────────┤
  │ Mock  │ 排除              │ 包含              │
  │ 收益  │                   │                   │
  ├───────┼───────────────────┼───────────────────┤
  │ 金额  │ $78.00            │ $94.90            │
  ├───────┼───────────────────┼───────────────────┤
  │ 差额  │ —                 │ $16.90（= Mock    │
  │       │                   │ 视频收益）        │
  ├───────┼───────────────────┼───────────────────┤
  │ 单数  │ 33（仅真实视频）  │ 208（含所有 PAID  │
  │       │                   │ 订单）            │
  └───────┴───────────────────┴───────────────────┘

  结论：不是 bug，是两个页面展示口径不同。Databoard
  展示的是"真实视频收益（不含Mock）"，通话订单页展示的
  是"所有已付款订单的总金额（含Mock）"。差额 $16.90
  就是 Mock 视频的收益。
